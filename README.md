# Journey Within — complete video download

**Channel: @journey.within.official**

## Download for Windows

[**Download the Windows starter ZIP**](https://github.com/KanishkThakar/journey-within-downloads/releases/download/v1.0.0/Journey_Within_Download_Starter.zip)

1. Extract the small starter ZIP into a folder on a drive with at least **65 GB free**. Use NTFS or exFAT, since the final ZIP exceeds 4 GB.
2. Double-click **Download-Journey-Within.cmd**. Windows PowerShell is included with Windows 10/11; no Python, Git, GitHub login or editing software is needed. The command is readable in this repository and does not change PowerShell execution policy.
3. Keep the window open while it downloads **16 parts (29.3 GB total)**. Each part and the joined ZIP are checked with SHA-256. If the connection fails, run it again; verified parts are reused. A partially downloaded part restarts.
4. When it says **SUCCESS**, right-click **Journey_Within_Windows_Package.zip**, choose **Extract All**, and open **index.html** inside the extracted folder. Verified temporary parts are removed automatically; the finished ZIP is kept.

[All download files / manual download](https://github.com/KanishkThakar/journey-within-downloads/releases/tag/v1.0.0)
